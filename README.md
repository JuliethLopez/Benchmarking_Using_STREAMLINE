# STREAMLINE

- This is a copy of the STREAMLINE repository [https://github.com/ScialdoneLab/STREAMLINE](https://github.com/ScialdoneLab/STREAMLINE)

- This pipeline was used to evaluate topological characteristics for networks produced on BEELINE framwork.

- Cite of original article: Stock M, Popp N, Fiorentino J, Scialdone A. Topological benchmarking of algorithms to infer gene regulatory networks from single-cell RNA-seq data. Bioinformatics. 2024;40: btae267. doi:10.1093/bioinformatics/btae267
